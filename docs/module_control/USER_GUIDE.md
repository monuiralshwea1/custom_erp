# USER_GUIDE — دليل استخدام لوحة التحكم

العنوان: **`/app/module-control-settings`** — تتاح لـ Administrator وSystem Manager فقط.
(الواجهة عربية RTL أولاً، مع أزرار وفلاتر مبنية على نفس مصدر بيانات واجهة التنقل.)

## 1. التخطيط العام

لوحة تحكم تفاعلية تُبنى أعلى نموذج الإعدادات وتتضمن:

```text
┌─ شريط الأدوات ───────────────────────────────────────────────┐
│ 🔄 فحص (Scan) │ ⚙️ مزامنة (Sync) │ 💾 طبّق التغييرات (Apply) │
│ 👁 معاينة الأثر │ 🧾 سجل التدقيق │ ↩ استرجاع الافتراضي      │
│ 🔎 بحث… │ فلتر: الكل / المخفية / المحظورة / المفروضة / المتغيّرة │
└──────────────────────────────────────────────────────────────┘
┌─ جدول الموديولات ─────────────────────────────────────────────┐
│ ☑ | الموديول + التطبيق | أعداد (dt/pg/rpt/ws) | الحالة | أزرار │
└──────────────────────────────────────────────────────────────┘
فضاء الجمعي + نتيجة الإصدار/آخر مزامنة/القواعد المفروضة
```

## 2. الأزرار: الوظيفة والسلوك الفعلي (مُصحّح بالتنفيذ)

- **فحص (Scan)** — جرد كل الـ Module Defs (59 في موقعك) مع عدّ DocTypes/Pages/Reports/Workspaces.
- **مزامنة (Sync)** — إعادة خطوة `run_sync` ثم `bump_version()` + `clear_cache()` — وتُصحّح القواعد تلقائياً (مثل إكمال `module_name` وإلغاء فرض القواعد التي أزيلت من config.py).
- **طبّق التغييرات (Apply)** — تمرير التغييرات للمسودة ومن ثم معاينة، ثم بعد تأكيدك، حفظ + فرض + `bump_version` + `clear_cache` + سجل تدقيق. مُصحّح فعلياً بجولة Projects.
- **معاينة الأثر** — عرض الفرق والإرب والتحذيرات قبل الحفظ (هناك موديولات مُسندتُها مسبقاً؛ تنبيهاً السحب واعتماديات التقرير تُبرهن).
- **سجل التدقيق** — آخر 25 عملية (المستخدم/الوقت/قبل-بعد/المصدر/الحالة) — مثال حقيقي موثق بالأسفل.
- **استرجاع الافتراضي** — إزالة كل القواعد التي يملكها النظام والاحتفاظ بالقواعد المفروضة من Python وإعادة الإعدادات الافتراضية.

## 3. الحالة (Traffic Chips) في الجدول

- **مخفي** / **محظور** / **مساحاته مخفية** — من المسوّدة الحية.
- **Enforced by Custom App** — قاعدة Python (زر التغيير معطّل).
- **تغييرات غير مطبقة** — مسودة غير حفظ (خلفية أرجوانية للصف).
- **ظاهر** — لا شيء مفعّل.
- عوامات العدد: `dt:Reports pg:2 rpt:3 ws:1`.

## 4. العمليات التي تتم دائماً من الجدول

| زر المسار | الوظيفة |
|---|---|
| 👁 إخفاء/إظهار | تبديل مسودة إخفاء الموديول (يربخ: إضافي يفعّل `hide_from_search` + `hide_all_workspaces`) |
| 🔒 حظر/فك | تبديل مسودة حظر الوصول + منع التنقل؛ فك الحظر يعمل بتنسخ Best للـ `block_protected_apis` |
| 🗂 المساحات | الحوار الديكريتي الفردي لكل مساحة (إخفاء/منع تنقل/Enforced) |
| ⚠ التبعيات | `get_module_impact`: مستندات مرتبطة من موديولات أخرى + تقارير خارجية (تحذير سابق للحظر) |

### تحديث الإجراء الجماعي (Bulk)

- تمكين Multi-select (عدّ عريض).
- إزالة/إضافة للمحدد: إخفاء/إظهار/حظر/فك — التنبيه يُذكر بالأسماء المفروضة من Python التي لن تتغير.

## 5. مثال جولة الإخفاء (نفس ما تم في الاختبار على Projects)

1. ابحث: `Projects` → انقر 👁 (إخفاء) → رُبطت جميع اإ Qu 工作 Workspace ى من الأوامر المدعومة.
2. اضغط 💾 طبّق — تظهر معاينة: `التصفية العامة للمساحات 0→1` + `Projects بدون قاعدة→قاعدة جديدة مفعلة`.
3. أكد: `تم التطبيق بنجاح ✅`، ثم تفريغ الكاش وتمرير التغييرات للجميع بأمان multi-worker.
4. نقطة التحديث: عدد مساحات الـ sidebar لجميّع المستخدمين (incl. Administrator) بدون Projects (تحقق فعلي).

## 6. مثال الجولة الفعلية للإخفاء ثم الإظهار من API (كما تم في الاختبار)

```javascript
// داخل الدسكتوب
await frappe.xcall('custom_erp.custom_app.module_control.api.save_and_apply', { payload: JSON.stringify({ rules: [], workspace_rules: [] }) });
```
نتيجة مشروحة: `Projects` عودة إلى sidebar؛ مسار `/app/projects` تفتح؛ قوائم `Project` عودة إظهارها.

## 8. قواعد الأمان عند الاستخدام

- لا تفعل **حظر الوصول** على موديولات مشتركة (Accounting, Stock, Sales) دون فحص «⚠ التبعيات».
- تنبيه المستخدم قبل الحظر بوثيقة تُقَاسمها موديولات أخرى (يُسجل التحذير داخل «معاينة الأثر»).
- عند الازعاج: **استرجاع الافتراضي** (بلا فقد بيانات) ثم التحليل.
